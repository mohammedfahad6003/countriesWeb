🌍 Country Details Web App

#Deployed at: countrydetails-pi.vercel.app

A responsive web application built using HTML, CSS, and Vanilla JavaScript, designed to provide users with comprehensive information about countries around the world. The application integrates with a public RESTful API to display real-time data including:

Country name, flag, population, region, subregion

Capital city, currencies, languages

Bordering (neighboring) countries with clickable navigation

Features include:

🔍 Search functionality for quick country lookup

🧭 Dynamic UI rendering for each country

💻 Deployed on Vercel for global accessibility

The app offers a clean and intuitive user experience, with seamless data fetching and navigation — ideal for users interested in geography or travel planning.
